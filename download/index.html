RELEASE INTEGRITY

Verify your download.

We publish a separate OpenPGP signature for each Windows installer. You can check the exact file before running it.

✓
01 / GET THE FILES

Download the installer and signature

Save the MSI and its matching .msi.asc file in the same folder. Also obtain the official public key.

Release files become available here after publication.
02 / CHECK THE KEY

Confirm the fingerprint

Compare the complete fingerprint to Recline's independently trusted announcement. A matching email address alone is not sufficient.

RECLINE RELEASE-SIGNING KEY / ED25519D7CE B113 4DCE 0311 F248 B631 8BA0 74B4 B137 5AD6
03 / VERIFY WITH GPG

Check the detached signature

With Gpg4win installed, run these PowerShell commands inside your downloads directory:

gpg --import .\recline-public-key.asc
gpg --fingerprint releases@recline.social
gpg --verify .\Recline_0.2.0-beta.1_x64_en-US.msi.asc .\Recline_0.2.0-beta.1_x64_en-US.msi

Look for Good signature, and verify that GPG reports the fingerprint shown above. GPG's local trust label alone does not prove the key owner's identity.

The release also includes a signed checksum manifest for checking downloaded assets.

BEFORE YOU INSTALL

What to expect.

WINDOWS INSTALLATION

Unknown publisher

The MSI has an OpenPGP release signature, but not a Windows Authenticode certificate. Windows may show an Unknown publisher warning, and some security settings may block installation. Do not bypass organization-managed security controls.

EXISTING ACCOUNTS

Your Recline, on desktop

Sign in with your existing account. You can choose whether the Windows application remembers your login on this device.

BETA SECURITY NOTE

Understand the limits

Space passphrases are currently transmitted to Recline's server for verification; the server can derive associated Space message keys. Uploaded attachments are not covered by text encryption. Avoid relying on this beta for highly sensitive conversations.
